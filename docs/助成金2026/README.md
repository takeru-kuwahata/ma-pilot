## この案件は何か

メディカルアドバンス社への**受託開発から、先方の自走への構造転換**。

```
現在   月30万円で弊社が受託（MA-Pilot・Lステップ・社内DX）
  ↓
移行   6ヶ月のAI活用研修（人材開発支援助成金）
       社員がブルーランプ（Claude Code）で自分で作れるようになる
  ↓
将来   先方が自走。弊社は伴走・レビューへ
```

日本医療DCの講座事業の一環でもある（同時期に鴻愛会・ぐるんとびーへも提案）。
インフラ面では GCPプロジェクト `ma-pilot-prod` を専用に切ってあり、
請求先を付け替えるだけで移管できる構成になっている（2026-08-29 完了）。

## 研修時間の決め方（2026-09-24 主君確定・社労士とMAとの調整の基準）

**請求額（月36万円・税別）を固定とし、受講料の全額が助成の対象になる時間に研修時間を合わせる。**
助成金の上限を超えてまで研修時間を増やさない。

要するに：**研修を月13.2時間以上やれば、受講料の75%が助成で戻る。**
これより短いと、受講料の一部が助成の対象から外れる。

### 受講料に対する助成（経費助成）

| 研修の月数 | 受講料（税別） | 受講料（税込） | 必要な研修時間 | 経費助成（75%） | 同社の実質負担 |
|---:|---:|---:|---:|---:|---:|
| 3か月 | 108万円 | 118.8万円 | 40時間 | 89.1万円 | 29.7万円 |
| 4か月 | 144万円 | 158.4万円 | 53時間 | 118.8万円 | 39.6万円 |
| 5か月 | 180万円 | 198万円 | 66時間 | 148.5万円 | 49.5万円 |
| 6か月 | 216万円 | 237.6万円 | 80時間 | 178.2万円 | 59.4万円 |

- 必要な研修時間＝受講料（税込）÷3万円（小数点以下は切り上げ）
- これより時間を増やしても、経費助成は増えない
- 今の54時間（6か月）のままだと、対象経費は162万円（54時間×3万円）に止まり、経費助成は121.5万円

### 研修中の給与に対する助成（賃金助成）

受講料とは別枠。研修の時間に同社が社員へ払う給与の補填であり、受講料の払い戻しではない。

- 1時間1,000円×受講者数（10名）。例：40時間なら40万円、80時間なら80万円
- 出席した人の分だけ出る。8割以上出席した人が対象（古山様 3/26）

### 根拠

- 古山様（9/24回答）：1時間3万円は**対象経費の上限**（助成額の上限ではない）
- 古山様（9/24回答）：**月ごとの配分に決まりはなく、偏りがあってもよい**。ただし計画申請は受講の1か月前までのため、10月に多く入れるのはスケジュールが厳しい
- 厚労省パンフレット：部外講師の謝金は「実訓練時間1時間当たり3万円が上限（**消費税込み**）」。経費助成は1人30万円まで（10〜100時間未満）。10名なら300万円で、上の表の範囲では上限に届かない
- 同パンフレット：対象経費は、支給申請までに事業主が全額負担していることが条件。経費助成が払った受講料を超えることはない
- 出典は令和5年版パンフレット（https://www.mhlw.go.jp/content/11600000/001103827.pdf）。令和8年8月改正での変更の有無は未確認

| | 事業外研修（パッケージ型） | **事業内研修（カスタマイズ型）** |

| 定義 | どの会社も基本は同じカリキュラム | **会社によりカリキュラムが変わる** |
| 助成上限 | 1人最大30万円 | **受講人数によらず1時間3万円まで** |
| 講師要件 | なし | **当該職務10年以上の職歴、または教える資格** |

**どちらを選んでも助成額はほぼ同額**（古山様の見立て）。

```
事業内: 54時間 × 3万円 = 162万円（対象経費の上限）
事業外: 請求216万円 × 75% = 162万円 ／ 10名 × 30万円 = 300万円が上限
→ どちらも 162万円
```

助成額が同じなら**事実に忠実な方を選ぶ**べきであり、本研修は同社固有の業務
（LINE・スプレッドシート・kintone の重複入力／内覧会実績・シフトの手作業集計／
歯科医院の先生との印刷物制作のやり取り）を題材に設計しているため、
**カスタマイズ型が事実**。パッケージ型と答えると 9/1 に古山様へ説明した
カリキュラムと矛盾する。

### 講師要件への回答方針（重要・今後も踏襲する）

事業内研修の講師要件は「当該職務で10年以上の職歴、または教える資格」。

**「AI活用10年」とは書かない**（事実に反する。AIで10年業務改善している人は日本にいない）。
制度が求めているのは *AI歴* ではなく **当該職務の職歴**。本研修の職務を
**「業務プロセスの改善設計・企画（デザイン）とその指導」** と捉えれば、

### 書類を作り直す場合の技術メモ

- xlsx はチェックボックス等の ctrlProps を保持するため **openpyxl を使わず XML を直接編集**する
  （スクリプトは scratchpad。`<sheetPr` の正規表現は `<sheetProtection` に誤ヒットするので注意）
- 期間欄は「年／月」の枠が別セル。`2008年5月` の塊で入れると枠からはみ出すため**数字だけ**を各枠に入れる
- PDF化は **Numbers** で書き出す（Excel の AppleScript 保存は失敗する。Numbers は印刷範囲を無視するので、
  本紙だけにするには出力後のPDFを増分更新で CropBox 指定して切り出す）

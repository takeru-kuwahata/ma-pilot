## この案件は何か

メディカルアドバンス社への**受託開発から、先方の自走への構造転換**。

```
現在   月30万円で弊社が受託（MA-Pilot・Lステップ・社内DX）
  ↓
移行   6ヶ月のAI活用研修（人材開発支援助成金）
       社員がブルーランプ（Claude Code）で自分で作れるようになる
  ↓
将来   先方が自走。弊社は伴走・レビューへ
```

日本医療DCの講座事業の一環でもある（同時期に鴻愛会・ぐるんとびーへも提案）。
インフラ面では GCPプロジェクト `ma-pilot-prod` を専用に切ってあり、
請求先を付け替えるだけで移管できる構成になっている（2026-08-29 完了）。

## 確定した条件（2026-09-01）

| 項目 | 内容 |
|---|---|
| 事業主体 | **株式会社医療Design Workshop** ※旧資料に別名表記あり。対外文書は必ずこの名義 |
| 弊社の請求 | **月36万円（税別）／人数によらず一定** |
| 期間 | 6ヶ月（3〜8ヶ月で調整可） |
| 訓練時間 | 54時間（集合36h＋グループ18h） |
| Claude利用料 | **先方が直接契約**。月20ドルのプランで可（事務局・金子さんが実証） |

| 申請主体 | メディカルアドバンス社（雇用保険適用事業所） |

### 人数別の先方ご負担（6ヶ月・現行180万円との比較）

| 人数 | 実質ご負担 | 現行比 |
|---:|---:|---:|
| 3名 | 155万円 | ▲25万円 |
| 5名 | 107万円 | ▲73万円 |
| 7名 | 92万円 | ▲88万円 |
| 10名 | 81万円 | ▲99万円 |

- **6名で経費助成が上限に達する**（請求216万円×75%＝162万円 vs 人数×30万円）
- 7名以降で増えるのは賃金助成のみ。ただし**人数が増えるほど負担は減る**
- 社労士費用は着手金10万円＋受給額の30%（＋税）。**先方にお支払いいただく必要がある**旨を開示済み

## 弊社の関与範囲（2026-09-01 確定）

| 弊社が答える | 先方（メディカルアドバンス社）の領域 |
|---|---|
| 研修の内容・時間・形式 | 受講人数の決定 |

作成は先方の業務であり、弊社が引き受けない（21_AI/CLAUDE.md の方針）。

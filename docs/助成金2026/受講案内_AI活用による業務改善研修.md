# 受講案内

## AI活用による業務改善研修

株式会社 医療Design Workshop

---

## 1. 講座概要

| 項目 | 内容 |
|---|---|
| 講座名 | AI活用による業務改善研修 |
| 実施機関 | 株式会社 医療Design Workshop |
| 期間 | 6ヶ月（3〜8ヶ月の範囲で調整可能） |
| 実訓練時間 | 合計54時間 |
| 内訳 | 集合研修 36時間（月6時間×6ヶ月）／グループ研修 18時間（月3時間×6ヶ月） |
| 実施形式 | 東京での集合研修と、同時双方向型オンライン研修の併用 |
| 実施単位 | 1社単位（受講企業ごとの個別開催） |
| 対象 | 営業・プロモーション・カスタマーサポート等の実務担当者 |
| 受講料 | 月額 360,000円（税別）／1社　※受講人数にかかわらず一定 |

---

## 2. 実施目的

受講者が、生成AIを用いて自らの担当業務の課題を解消できる状態になること。

一般的なAIの座学ではなく、受講者が現に担当している業務を題材とし、
受講者自身が実際に動く仕組みを構築する形式をとる。
研修終了時点で、受講者が自社の業務改善を継続して進められる状態を到達点とする。

---

## 3. カリキュラム

| 月 | 内容 | 成果物 |
|---|---|---|
| 1ヶ月目 | AIを業務で使えるようにする<br>日報・報告メール・議事録など、日常的に発生する文書作成から着手する | 担当業務における時間短縮の記録 |
| 2ヶ月目 | 自分の業務の課題を洗い出す<br>担当業務のどこに手間がかかっているかを受講者自身が整理する | 部署ごとの課題整理シート |
| 3ヶ月目 | 繰り返し入力をなくす<br>複数のツールへ同じ情報を入力している作業をシステム連携で解消する | 実際に動く連携の仕組み（1件以上） |
| 4ヶ月目 | 実績を自動で集計する<br>手作業で行っている実績集計・シフト管理等を自動化する | 実績集計の画面 |
| 5ヶ月目 | 顧客とのやり取りをデジタル化する<br>取引先からの依頼受付をオンライン化する仕組みを検討・試作する | 試作版と、運用に載せるための課題整理 |
| 6ヶ月目 | 研修後も自社で続けられるようにする<br>構築した仕組みの手順を社内資料として残し、引き継げる状態にする | 社内手順書と、次の取り組み計画 |

各月の題材は、受講企業の実業務に合わせて設定する。

---

## 4. 実施スケジュール

| 区分 | 頻度 | 1回あたり | 実施場所 |
|---|---|---|---|
| 集合研修 | 月2回 | 3時間 | 東京（会場）または同時双方向型オンライン |
| グループ研修 | 月3回 | 1時間 | 同時双方向型オンライン |

いずれも講師と受講者が同時双方向で実施し、受講中に質疑応答を行う。
録画配信による一方向の講義は行わない。

具体的な実施日は、受講企業との協議により決定する。
